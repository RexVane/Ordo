# Ordo v1.0.2 Release Notes / 发布说明

v1.0.2 hardens the default distribution: vector backends no longer accept
placeholder implementations, the default PDF parser no longer requires the
AGPL-licensed PyMuPDF package, and release versions are checked consistently
across the app, web package, Helm chart, and documentation.

v1.0.2 是一次面向**默认发行版**的加固版本：向量后端不再接受占位实现，默认 PDF
解析器不再依赖 AGPL 授权的 PyMuPDF，应用、前端、Helm Chart 与文档的版本号由脚本
统一校验。

## Snapshot / 概览

| Area | v1.0.2 outcome |
| --- | --- |
| Vector backends | `qdrant` / `pgvector` placeholders are rejected; unknown backends fail fast instead of silently returning empty results. |
| Ephemeral storage | `VECTOR_BACKEND=memory` is marked ephemeral and refused in production by settings validation. |
| PDF parsing | The default `basic` parser uses `pdfplumber` + `pypdf` + `pypdfium2`; PyMuPDF moves to an opt-in AGPL extra. |
| Licenses | The default image and `requirements.txt` contain no AGPL runtime dependency. |
| Releases | `scripts/release/check_versions.py` and `make release-check` keep app, web, Helm, README, and release notes aligned. |
| Database | No new migration. |

## Upgrade / 升级

No database migration is introduced by this release. Rebuild the API, worker,
and web images, then run the normal readiness and knowledge-base smoke checks.

本版本不包含数据库迁移。重新构建 API、Worker 与 Web 镜像后，执行常规就绪检查和
知识库闭环验证即可。

```bash
git fetch --tags
git checkout v1.0.2
make init
make up-web
make api-ping
```

If a deployment explicitly selected `VECTOR_BACKEND=qdrant` or
`VECTOR_BACKEND=pgvector`, those placeholders never persisted vectors. Switch
to `milvus`, `faiss`, or `chroma` and re-ingest the affected datasets before
serving traffic.

如果部署中显式选择了 `VECTOR_BACKEND=qdrant` 或 `VECTOR_BACKEND=pgvector`，这些
占位实现从未持久化向量。请切换到 `milvus`、`faiss` 或 `chroma`，并重新入库相关
数据集后再对外提供服务。

## PDF parser and licensing / PDF 解析与许可证

The default `basic` PDF parser now uses the already-installed
`pdfplumber`/`pypdf` stack. PyMuPDF is only needed by optional OCR/preprocess
features; install `requirements-agpl.txt` and enable the AGPL extra explicitly
if you need them and accept the AGPL-3.0 obligations.

默认的 `basic` PDF 解析器改用仓库已有的 `pdfplumber`/`pypdf` 组合。PyMuPDF 仅
供可选的 OCR/预处理功能使用；如确需这些功能并接受 AGPL-3.0 义务，请显式安装
`requirements-agpl.txt` 并启用 AGPL extra。

## Verification / 验证

- `make check-versions` passes.
- `pytest -q tests/test_pdf_parser_parity.py tests/test_vector_backend_contracts.py`
- `python -m app.rag.evaluation.parse_bench run ... --strict` on the golden corpus.
- `make api-ping` returns ready with the expected vector backend metadata.

The v1 retrieval benchmark methodology and measured results remain those
published with v1.0.0; this patch does not claim a new accuracy or latency run.
See [the benchmark record](../benchmarks/changzhou_dify.md).

800 题方法与实测指标沿用 v1.0.0 已发布记录；本补丁不宣称新的准确率或时延结果。
